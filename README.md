# ProjectINc Departure Lounge

Interactief prototype van de onboarding voor ProjectINc (CMD Hanze, PFI). Gemaakt door Stefan Top.

Live zetten met GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

Lokaal bekijken: open de map met een lokale server, bijvoorbeeld `python3 -m http.server`, en ga naar http://localhost:8000. Dubbelklikken op index.html werkt niet: de browser laadt de 3D-bestanden dan niet.

three.js (MIT-licentie) staat in de map `lib`.
